# Roadmap

The current delivery is a deterministic synthetic decision laboratory. Extend it only after the complete existing journey and its evidence remain reproducible.

## Delivery gates

1. Finish real-browser and disconnected-localhost verification; record actual screenshots and a genuine two-minute demo.
2. Reproduce setup from a clean environment, verify exports and preserve dependency locks.
3. Complete authorized public GitHub publication and verify repository visibility/creation metadata. Publication is currently blocked by automatic approval review and is not completed.
4. Finalize the submission's real links, team credits, AI disclosure and chosen track. Check actual sponsor briefs before making eligibility claims. No award outcome is predictable or guaranteed.

## Model quality

- Compare policies against greedy and neutral optimization over a declared broader scenario/shock suite. Preserve unfavorable results, paired no-replan controls and independent receipts.
- Report compute latency and watchdog/fallback frequency across supported environments before asserting performance targets.
- Work with a food-bank coordinator to validate orders, loading, shifts, priorities and operational constraints using authorized data. Keep synthetic demonstrations separate from field validation.
- Add uncertainty only with explicit distributions, reproducible seeds, sensitivity analysis and uncertainty reporting.

## Physical extensions

General multitrip routing, driver reassignment, multiple breakdowns, rescue/transfers and spoilage require new custody/timing semantics and independent adversarial tests. They are not implemented shortcuts. Add each only when a validated operational need justifies the complexity.

## Optional AI and integrations

A future bounded LLM strategist could propose policy parameters or candidate routes through typed tools. It would need explicit provider/budget setup, real traces, timeouts, tested failure handling and deterministic fallback. The simulator and referee must retain authority over facts and validity. Current code has no live LLM or deepagents capability.

Real demand imports, routing data, dispatch/messaging and sponsor APIs require a concrete brief, authorized test destination, privacy design and verified end-to-end behavior. Exporting a simulated plan does not establish such an integration. Do not attach sponsor claims to a planned dependency.

## Beyond the demonstration

Before real operational use, establish validated data, access controls, multi-user concurrency, retention/audit policy, operator review, incident handling and field trials with an explicit evaluation protocol. The current local single-process SQLite application is not a production dispatch service.
