# Scenario Studio release verification

Verified locally on November 14, 2026, on macOS arm64 with Python 3.13.12, Node 24.18.0, the existing locked dependencies and the project's official Playwright Chromium. No runtime model-provider calls or API key were used.

## Delivered behavior

The default application is now an editable, prefilled Scenario Studio. Its bounded readable compiler produces a strict `fork-workflow/1` data model, facts-to-model trace, explicit assumptions and blocking issues. Repair clinics, event production and IT response run through one shared minute-discrete scheduler. The existing vehicle/road/cargo simulation remains unchanged at `?view=logistics`.

Three workflow policies execute actual capacity-, stock-, dependency- and budget-constrained work. Multiple resource outages rerun equal starting models. Unshocked results and a paired fixed-plan control remain visible, including losses and ties. Independent standard-library replay recomputes metrics. Approval and export bind the selected future, current revision, model, evidence and preferences; export replays evidence and requires an exact type-sensitive receipt match.

The browser preserves drafts and the saved experiment pointer, blocks stale approval/export, serializes writes and uses stable idempotency keys. New scenario preserves stored experiment IDs; revisions of one experiment overwrite its latest snapshot rather than forming an immutable revision archive.

## Review corrections

Independent backend review found two P2 issues: approval/export did not compare the entire displayed verification receipt, and cost scoring used a different denominator from the declared budget. Both were reproduced with failing regressions, corrected and independently reverified. Receipt integrity is canonical and type-sensitive, including boolean/integer substitutions.

Whole-change review independently reproduced three P2 UI races: retry could discard a newer draft, compilation could clear an unresolved save revision, and a late template could overwrite newly typed text. Each is fixed with browser regression coverage. Selecting a different future after approval also requires a fresh selection-specific approval. Both review verdicts are PASS with no unresolved blocking findings in their declared scope.

Final visual polish raised form/control/body readability, added accessible focus treatment, and clipped the unfocused skip link so full-page screenshots cannot expose an offscreen fixed element. Its normal keyboard-focus behavior remains available. Current desktop/model/mobile screenshots were inspected after recapture. Original logistics artifacts regenerated by the regression suite were restored to their previously reviewed versions; new Studio evidence is kept separately.

## Boundaries

The compiler accepts documented statements and clauses; it does not infer arbitrary language, missing physical laws, stochastic behavior or faithful domain assumptions. The workflow engine uses checkpointable jobs that retain one pool. Scheduling is heuristic, not a global optimizer. Replay certifies declared model consistency, not safety, operational truth or field performance. Priorities and all example inputs are synthetic/user-declared.

The JSON schema endpoint is the future AI authoring seam. A later provider adapter must propose typed inputs and pass the same review, validation and evidence gates. No provider connection, deepagents integration or autonomous outcome generation is currently implemented. The user deferred API-key setup.

Supported deployment remains one localhost backend process. No new clean-machine dependency installation, all-browser validation, formal accessibility audit, multi-process concurrency, public Studio upload, hosted deployment or competition submission is claimed in this update. The original logistics repository publication remains separate from this local enhancement.
