# FORK identity

**Rehearse before you commit.**

FORK makes a difficult decision feel inspectable. Its personality is calm, curious and precise: ask a useful question, show the consequence, let the person decide. The product should feel like a quiet working surface rather than a command center.

## Visual system

| Role | Value |
|---|---|
| Paper | `#F7F7F2` |
| Surface | `#FFFFFF` |
| Ink | `#17221D` |
| Muted text | `#627066` |
| Hairline | `#DDE1D9` |
| Green | `#5C7658` |
| Soft accent | `#D8E4D0` |

Use generous empty space, thin borders, soft corners and restrained motion. Use the system sans-serif stack, with the existing serif emphasis as a quiet editorial accent. Avoid decorative gradients, neon, dense badges and large shadows. Color distinguishes policies and states; names and labels must also carry the meaning.

The three branches of the FORK mark represent possible decisions from one starting point. Keep the mark simple, monochrome and unboxed. Use the same [mark](../frontend/public/fork-mark.svg) and [wordmark](../frontend/public/fork-wordmark.svg) in the application and video. The mark is FORK's own; the minimal editorial direction takes inspiration from OpenAI's restraint without implying affiliation.

## Voice

Say “Compare plans,” “Apply a breakdown,” “Inspect evidence” and “Approve simulated plan.” Prefer a concrete verb and a short explanation. Show uncertainty, baseline wins and ties directly. Explain a technical mechanism when it helps someone assess the result.

Avoid victory language, invented agent thinking, guarantees, or claims of real meals delivered. “This run recovered 24 meals compared with its fixed-plan control” is stronger than an unsupported claim about better decisions.

## Film

The film uses the same paper, ink, green, mark and concise labels. Number the chapters and keep the active step visible without covering evidence. Leave settled time after clicks so a viewer can read the real result. Narration and captions must agree. Close once: a restrained reveal/fade of the FORK mark, then the mark alone. No unrelated logo, confetti, or sponsor claim.

Shared application tokens live in [brand.css](../frontend/src/brand.css). The logistics map uses neutral roads, legible labels and restrained policy colors. Scenario Studio, the walkthrough and the film use the same identity.
